# Teams Email Notification Flow

## Overview
This Power Automate flow automatically:

1. Detects a new Microsoft Teams channel message
2. Retrieves the sender's profile
3. Sends an email notification
4. Waits for a specified delay
5. Posts a reply back to the Teams channel

## Technologies
- Microsoft Teams
- Power Automate
- Outlook

## Use Case
Automated notification and acknowledgment workflow for team communications.
